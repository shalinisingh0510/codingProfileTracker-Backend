# Percentages (TCS NQT Aptitude)

## 1. Basics of Percentage
**Definition:** Percentage means “per hundred”.

```text
x% = x / 100
```

**Quick examples:**
- 25% = 25/100 = 1/4
- 50% = 1/2
- 75% = 3/4

## 3. Core Percentage Formulas

### Formula 1: x% of y
```text
x% of y = (x/100) * y
```
Example (fast):
- 20% of 250 = (1/5) of 250 = 50

### Formula 2: “What percent is A of B?”
```text
Percentage = (A / B) * 100
```
Example:
- 40 is what percent of 200? = (40/200)*100 = 20%

### Formula 3: Percentage Increase / Decrease
```text
% Increase = (Increase / Original) * 100
% Decrease = (Decrease / Original) * 100
```

---

## 4. Most Important Tricks for TCS NQT (Speed)

### Trick 1: x% of y = y% of x
Example:
- 25% of 80 = 80% of 25 = 20

### Trick 2: Shortcut Percentages
| Percentage | Shortcut |
|---|---|
| 10% | divide by 10 |
| 20% | divide by 5 |
| 25% | divide by 4 |
| 50% | divide by 2 |
| 5% | divide by 20 |
| 1% | divide by 100 |

Example:
- 25% of 640 = 640/4 = 160

### Trick 3: Successive Percentage Change (Increase then Increase)
```text
Net % change = a + b + (a*b)/100
```
Step-by-step example:
- Increase 20% then 10%
- Net = 20 + 10 + (20*10)/100 = 32%

### Trick 4: Same % Increase then Same % Decrease
```text
Net % change = - (x^2)/100
```
Example:
- +20% then -20% => net = -(20^2)/100 = -4% (overall 4% decrease)

### Trick 5: New Value Formula
```text
New = Old * (1 ± x/100)
```

## 5. Profit/Loss & Discount Use Percentages
```text
Profit% = (Profit / CP) * 100
Loss%   = (Loss / CP) * 100

SP = CP * (1 + Profit%/100)
SP = CP * (1 - Loss%/100)
```

### Successive Discounts
```text
Net discount = a + b - (a*b)/100
```
Example:
- 20% and 10% discount => 20 + 10 - 2 = 28%

---

## 6. Reverse Percentage Trick
If value becomes **A** after **x% increase**:
```text
Original = (A * 100) / (100 + x)
```
If value becomes **A** after **x% decrease**:
```text
Original = (A * 100) / (100 - x)
```

Step-by-step example:
- Salary after 20% increase = 36000
- Original = 36000*100/120 = 30000

---

## 7. Fast Calculation Habits (1-minute rule)
- Convert to fractions whenever possible: 12.5% = 1/8, 33.33% = 1/3, 66.67% = 2/3.
- For “increase then decrease”, use the square shortcut quickly.
- Avoid long multiplication: rewrite percentage as a simple fraction first.
