# Ratio and Proportion (TCS NQT Aptitude)

## 1. Basics
**Ratio** compares quantities of the same unit.

```text
a : b = a/b
```

**Proportion** means two ratios are equal.
```text
a:b = c:d  =>  a/b = c/d  =>  a*d = b*c
```

---

## 2. Core Formulas

### Cross multiplication
```text
a:b = c:d  =>  a*d = b*c
```

### Divide in a ratio (total T)
```text
If A:B = m:n, then
A = T * m/(m+n)
B = T * n/(m+n)
```

### Continued proportion
```text
a:b = b:c  =>  b^2 = a*c
```

### Componendo & Dividendo (speed trick)
If
```text
a/b = c/d
```
then
```text
(a+b)/(a-b) = (c+d)/(c-d)
```
Use when expressions involve (sum/diff) patterns.

---

## 3. Fast Tricks (1-minute)

### Trick 1: Scale ratios quickly
```text
If a:b = 2:3 then 4:6, 6:9 ... are same ratio.
```

### Trick 2: Convert statement to equation
Example:
- A:B = 3:5 and A+B=64
- A=64*(3/8)=24, B=64*(5/8)=40

### Trick 3: Direct vs inverse proportion
- Direct: x increases => y increases (y = kx)
- Inverse: x increases => y decreases (y = k/x)

## 4. Practice Questions (10)
**Q1.** If A:B = 3:5 and A+B=64, find A and B.  
**Q2.** If x:y = 4:7 and y:z = 3:5, find x:z.  
**Q3.** Divide 560 in the ratio 2:5.  
**Q4.** If a:b = 5:8 and b:c = 4:9, find a:c.  
**Q5.** The ratio of boys to girls is 7:5. If there are 40 girls, how many boys?  
**Q6.** A sum is divided among P, Q, R in ratio 1:2:3. If R gets 2400, find total sum.  
**Q7.** If 12 workers finish a job in 15 days, how many days for 18 workers (same efficiency)?  
**Q8.** If A:B = 2:3 and B:C = 4:5, find A:B:C in simplest form.  
**Q9.** If a:b = 7:9, by what percent is a less than b?  
**Q10.** If x is directly proportional to y and x=15 when y=10, find x when y=18.

---

## 5. Answers
**A1.** A=24, B=40  
**A2.** x:y=4:7, y:z=3:5 => y=LCM(7,3)=21 => x=12, z=35 => x:z = 12:35  
**A3.** 560*(2/7)=160 and 560*(5/7)=400  
**A4.** a:b=5:8, b:c=4:9 => b=LCM(8,4)=8 => a=5, c=18 => a:c = 5:18  
**A5.** Boys = (7/5)*40 = 56  
**A6.** R is 3 parts = 2400 => 1 part = 800 => total parts=6 => total=4800  
**A7.** Work = workers*days => 12*15 = 18*d => d=10  
**A8.** A:B=2:3 and B:C=4:5 => make B same: A:B=8:12, B:C=12:15 => A:B:C=8:12:15  
**A9.** a/b = 7/9 => a is (2/9) less than b => (2/9)*100 = 22.22%  
**A10.** x/y = 15/10 = 3/2 => x = (3/2)*18 = 27
